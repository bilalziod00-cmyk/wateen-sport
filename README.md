# وتين سبورت (Wateen Sport) — تطبيق أخبار وبطولات الرياضة الأردنية

تطبيق أندرويد وويب متكامل باللغة العربية (**RTL**) بهوية داكنة مستوحاة من الملاعب الأردنية، مبني باستخدام **React + TypeScript + Tailwind CSS + Capacitor Android + Firebase**.

## أبرز المميزات
- **الهوية والتصميم:** واجهة داكنة رياضية سريعة بدعم كامل للغة العربية (RTL)، أيقونة مخصصة، وشاشة بداية (Splash Screen).
- **شريط تنقل سفلي من 4 أقسام:**
  1. **الرئيسية:** شريط الأخبار العاجلة، البنرات الرئيسية، أبرز المباريات بتوقيت عمّان، البطاقات والتصاميم الرياضية القابلة للمشاركة، وآخر الأخبار مع البحث والفلترة.
  2. **البطولات:** تغطية شاملة لكل من:
     - دوري المحترفين الأردني
     - دوري الدرجة الأولى الأردني
     - دوري الدرجة الثانية الأردني
     - دوري الدرجة الثالثة الأردني
     - الفئات العمرية (**تحت 20، تحت 17، تحت 15، والواعدين**)
     - كأس الأردن والمنتخبات الوطنية (النشامى)
     - صفحة متكاملة لكل بطولة تضم: جدول الترتيب، جدول المباريات، الهدافين والإحصائيات، وأخبار البطولة.
  3. **النتائج والترتيب:** نتائج المباريات المباشرة والسابقة والقادمة بالملاعب الأردنية وتوقيت عمّان (`Asia/Amman`)، وجداول ترتيب جميع الدرجات والفئات.
  4. **لوحة التحكم الإدارية (خاصة بالمالك):** محمية برمز دخول سري (الافتراضي `2026`)، وتتيح:
     - إضافة وتعديل وحذف الأخبار ووسمها كعاجلة وإرفاق بطاقات إحصائية ورفع الصور.
     - إدارة نتائج المباريات مباشرة (+1/-1)، الحالة (قادمة / مباشر / انتهت)، الملاعب، والأهداف.
     - تعديل جداول الترتيب وقوائم الهدافين لأي دوري أو فئة عمرية.
     - إدارة البنرات الرئيسية والبطاقات الرياضية.
     - بث الإشعارات الفورية (Push Notifications عبر FCM).
     - المزامنة السحابية الفورية مع Firebase والنسخ الاحتياطي JSON.
- **المشاركة السريعة:** مشاركة الأخبار والمباريات والبطاقات مباشرة عبر واتساب، فيسبوك، إنستغرام، وقائمة مشاركة أندرويد الأصلية.

## هيكلية المشروع
```text
wateen_sport/
├── src/
│   ├── types/sports.ts                # نماذج البيانات الرياضية
│   ├── constants/competitions.ts      # تعريف البطولات والفئات والملاعب الأردنية
│   ├── data/seedData.ts               # بيانات تأسيسية شاملة للكرة الأردنية
│   ├── services/
│   │   ├── firebaseService.ts         # المزامنة اللحظية Firestore + Storage + FCM
│   │   └── nativeAndroid.ts           # تهيئة أندرويد (StatusBar, SplashScreen, Push)
│   ├── context/AppDataContext.tsx     # إدارة الحالة السحابية والمحلية ولوحة التحكم
│   ├── utils/                         # توقيت عمّان، المشاركة السريعة، وضغط الصور
│   ├── components/                    # MatchCard, StandingsTable, SportsCardItem, ShareSheet
│   └── pages/                         # الرئيسية، البطولات، النتائج، تفاصيل الخبر/المباراة، ولوحة التحكم
├── android/                           # مشروع Android Gradle المولّد عبر Capacitor (com.wateensport.app)
├── firebase/                          # قواعد Firestore + Cloud Function لبث إشعارات FCM
├── download-page/                     # صفحة هبوط عربية جاهزة للتحميل المباشر لملف APK
├── scripts/apply-android-branding.ps1 # توليد أيقونات وشاشة بداية وإعدادات RTL لأندرويد
├── .github/workflows/build-apk.yml    # بناء تلقائي لملف APK ورابط تحميل مباشر على GitHub
└── BUILD_AND_DEPLOY_GUIDE.md          # الدليل الكامل لتشغيل وربط وتصدير الـ APK
```

راجع ملف [BUILD_AND_DEPLOY_GUIDE.md](./BUILD_AND_DEPLOY_GUIDE.md) للخطوات الكاملة لبناء ملف الـ APK ونشر رابط التحميل المباشر.
